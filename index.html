مقدمة وأهداف المشروع

Rally موقع ويب لحجز ملاعب البادل بالساعة، ويتيح لصاحب الحجز تقسيم المبلغ بين اللاعبين ومعرفة من دفع ومن بقي عليه. الحجز بالاتصال أو الرسائل يسبب حجوزات مكررة ويصعّب معرفة الساعات المتاحة ويجعل تحصيل المبلغ غير منظم، فيحل الموقع ذلك بجدول مواعيد واضح لكل ملعب وقفل تلقائي للساعة عند حجزها وتقسيم محسوب للمبلغ.

تحليل المتطلبات

الزائر

  • تصفح الملاعب وتصفيتها حسب النوع (بانوراما، داخلي، خارجي)
  • اختيار تاريخ خلال 14 يومًا وعرض الساعات المتاحة والمحجوزة
  • حجز من ساعة إلى 3 ساعات بإدخال الاسم والجوال
  • استلام رقم حجز مثل RLY-20261125-0007
  • الاستعلام برقم الحجز وإضافة اللاعبين وتأكيد الدفع

صاحب الملعب

  • إضافة ملعب وتعديله وحذفه مع رفع الصورة
  • تحديد سعر الساعة وأوقات الفتح والإغلاق
  • عرض الحجوزات وتصفيتها وإلغاء أي حجز لتعود ساعاته متاحة
القرارات المعتمدة: لوحة التحكم بدون تسجيل دخول · مدة الحجز من 1 إلى 3 ساعات · الدفع حالة فقط (دفع / باقي) بدون دفع إلكتروني · الحد الأقصى 4 لاعبين لكل حجز.

آلية الحجز وتقسيم المبلغ

خطوات الحجز في book.php

  1. استقبال بيانات النموذج بالطريقة POST
  2. التحقق من المدخلات: الاسم، الجوال (10 أرقام يبدأ بـ 05)، المدة من 1 إلى 3، التاريخ، وأن الوقت ضمن ساعات العمل ولم ينتهِ
  3. استعلام SELECT عن الساعات المطلوبة في booking_slots، وإذا رجعت صفوف بـ mysqli_num_rows يُرفض الحجز
  4. حفظ الحجز بـ INSERT ثم توليد رقم الحجز: RLY- + date('Ymd') + رقم الصف من 4 خانات
  5. قفل الساعات بإدخال صف لكل ساعة في booking_slots فتظهر محجوزة فورًا
  6. إضافة صاحب الحجز أول لاعب ويتحمل كامل المبلغ حتى يضيف لاعبين
حماية مزدوجة: فحص في PHP قبل الحفظ، وقيد UNIQUE في القاعدة كاحتياط.

تقسيم المبلغ

حصة اللاعب = السعر الكلي ÷ عدد اللاعبين. عند إضافة لاعب أو حذفه تُعاد حصة الجميع. مثال: حجز بـ 320 ريال، لاعبان يدفع كل واحد 160، وثلاثة 106.67، وأربعة 80.

لكل لاعب زر لتأكيد الدفع أو إلغائه، ويظهر المدفوع والمتبقي ونسبة التحصيل. المبالغ غير المتساوية تُقرَّب إلى خانتين عشريتين.

لوحة تحكم صاحب الملعب

اللوحة في مجلد admin وتفتح بدون تسجيل دخول، وتحتوي على:

  • الإحصائيات: عدد الملاعب، حجوزات اليوم، الحجوزات القادمة، إيراد الحجوزات القادمة
  • إدارة الملاعب: إضافة وتعديل وحذف، مع السعر وأوقات الفتح والإغلاق والصورة
  • رفع الصور: بالدالة move_uploaded_file مع التحقق من الامتداد (jpg / png / webp)
  • إدارة الحجوزات: عرض مع حالة الدفع، تصفية بالملعب والتاريخ، وإلغاء حجز لتعود ساعاته متاحة

لا يسمح النظام بتغيير أوقات العمل إذا كانت هناك حجوزات قادمة خارج الأوقات الجديدة.

التطوير المستقبلي والخاتمة

حدود المشروع

  • لوحة التحكم بدون تسجيل دخول
  • الاستعلامات بدمج المتغيرات كما في المحاضرات ولا تحمي من SQL Injection في موقع حقيقي
  • الدفع حالة فقط وليس دفعًا إلكترونيًا

تطويرات مقترحة

  • تسجيل دخول بـ Sessions
  • استعلامات مجهّزة (Prepared Statements)
  • ربط بوابة دفع
  • رسائل تأكيد للاعبين

حقق المشروع هدفه ببناء موقع متكامل بـ PHP و MySQL يعرض الملاعب ويدير الحجوزات بلا تكرار ويقسم المبلغ بين اللاعبين ويمنح صاحب الملعب لوحة إدارة، مستخدمًا ما درسناه في المقرر: الاتصال بقاعدة البيانات والنماذج وأوامر SELECT و INSERT و UPDATE و DELETE والدوال ورفع الملفات.
